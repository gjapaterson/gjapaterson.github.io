Privacy policy

Last updated: 23 September 2026

Fenwood Nest is a personal program run by a single household on its own computer. It has no users other than that household's owner.

What it accesses

With the owner's explicit consent, it reads data from the owner's own Google Nest devices through Google's Smart Device Management API: current temperature, humidity, thermostat mode and target temperature.

What it does with that data

The data is displayed on a dashboard and stored on the owner's own computer. It is not transmitted to any third party, not published, not sold, not used for advertising, and not used to train anything.

Who can see it

Only the owner. There is no shared server and no other user.

Access tokens

The credential that permits this access is stored locally on the owner's computer, readable only by the owner's account. Access can be withdrawn at any time from the owner's Google Account permissions page, which immediately stops all access.

Contact

Enquiries may be sent to the support address shown on the Google consent screen for this application.
